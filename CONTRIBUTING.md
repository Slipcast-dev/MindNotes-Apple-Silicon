# Contributing · Участие в проекте

**English**

This is the owner's personal project; the repository is open for reading. Outside changes are accepted only by prior agreement; see [LICENSE](LICENSE).

- The working branch is `personal-ru`; milestones are described in [PLAN.md](docs/personal-ru/PLAN.md) (Russian).
- Run `./scripts/test.sh` before committing; layer rules are in [ARCHITECTURE.md](docs/en/ARCHITECTURE.md).
- Results are recorded in [STATUS.md](docs/personal-ru/STATUS.md) and [TEST_REPORT.md](docs/personal-ru/TEST_REPORT.md).
- Issues and pull requests may be written in English or Russian.

Code of conduct: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
