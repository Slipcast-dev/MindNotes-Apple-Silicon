# Known limitations and risks

**English** · [Русский](../personal-ru/KNOWN_LIMITATIONS.md)

- **Apple silicon and macOS 15 or newer** (ADR-0009, ADR-0020). New builds do not run on Intel or on macOS 13–14. Checked by hand on macOS 27.2; on macOS 15 (15.8.2) and 26 (26.7.2) only by automated tests and a launch check in CI.
- **macOS 15 looks different.** There is no Liquid Glass there: the toolbar and standard controls use the older style.
- **Not checked on this build.** Manual input, VoiceOver, Writing Tools. The system Liquid Glass capsules in the window title bar are turned off; other standard controls may still get the new look.
- **Performance.** The development machine is weaker than the reference one (M1 with 8 GB vs. Apple silicon with 16 GB). The AT-17 targets are not confirmed here; the benchmarks in `TEST_REPORT.md` run without rendering.
- **Writing Tools.** Turned off only in the editor text. Titles, database properties, filters and search may not be covered; not tested with Apple Intelligence.
- **Signing.** The build is ad-hoc signed; this is not notarization.
- **Editor.** Dragging text is disabled; multi-range edits are rejected. A to-do checkbox is not a separate VoiceOver element.
- **First upgrade of a large workspace.** The migration builds the search index in one transaction without a progress indicator: on 100,000 blocks this may take noticeable time (not measured at that size).
- **Search.** Words and prefixes only, no Russian morphology: an inflected form is found only by its prefix.
- **Inline database card.** The five-record card remains for versions without live views and for an unavailable database.
- **Calendar and board.** The grid shows up to 1,000 records and warns when there are more; card order inside a column follows the sort and cannot be changed by hand. Grouping only by status, select and checkbox.
- **Templates.** “Simple pages” are pages with starter text; a record template with properties is saved from its own record. A page template with an inline view points at the original database. The template catalog is built into the app: you cannot add your own templates to it and there is no online store; catalog templates do not use Person or Files & media properties.
- **Totals and timeline table.** Column totals are calculated only in Table views and are skipped when more than 50,000 records match the filter. The width of the table beside the timeline is not kept between launches; its columns are the visible properties of the same view.
- **Databases.** Property values are not in ⌘K search or in history snapshots. A date-time filter compares by day in the value's own time zone. The in-memory page list includes records and is reread on every page open (34 ms for 20,000).
- **Export.** Portable, not a backup: version history, database views, the trash and templates are not included. Underline and colour cannot be expressed in Markdown and are noted in the report. A database record's page is exported only if it has text.
- **Import.** Nested Markdown lists are flattened. From Notion: pages, page nesting, tables with rows, images and links; relations come over if both databases are in the archive (a column linking to several databases or only to records outside the archive stays text); Notion formulas and rollups arrive as text values, views are not imported. Relations from our own CSV export (titles without paths) stay text on re-import. Notion dates in English format (“March 8, 2026”) become text. Files not referenced by any page are not imported and are counted in the report. Limits: 20,000 files and 4 GB, text up to 32 MB. An interrupted import keeps what was already created under the import page.
- **History.** The page title is not part of snapshots. Old snapshots are thinned only for pages that are opened and changed.
- **Navigation on a save error.** If saving fails, moving to another page is refused with a message until saving recovers; the text is available through the emergency export.
- **Export language.** The inline-view note in exported Markdown is always in Russian. Snapshot reasons are stored in Russian and translated when shown.
- **Automatic backups** are made only while the app is open. Rotation deletes old automatic backups permanently; manual ones are kept. If the chosen folder is unavailable (disk disconnected), no backup is made and the app says so.
- **Video** shows on the page as a poster frame and plays in an app window on click, not inline: the TextKit 1 editor cannot host a live player inside text. Audio is inserted as a file.
- **Sidebar drag** does not auto-scroll: to move onto a row off screen, use “Move to…”.
- **Relations.** A relation and “Created”/“Edited” cannot change type, and other properties cannot be changed into them. A new record cannot be created from the picker, which shows the first 50 records — refine the search for more. The “contains record” filter matches part of the title, not the chosen record. Editing a relation updates “Edited” only on the edited record, not on the other side. A former reverse side that became standalone after copying a database has no defined relation order. Version 1.0 cannot open a schema v6 workspace.
- **Rollups.** Rollup settings cannot be changed after creation: delete and recreate. “Edited” cannot be a source, otherwise every edit would recalculate related records. An unknown aggregate from a newer version is not computed or shown, but its values are kept. A stored percentage is a number from 0 to 100; “%” is added for display.
- **Formula language.** English function names only; no lists or list functions. The step limit counts tree nodes, not string length. A chain of more than 128 operations in a row is rejected: split it into several properties. A property value longer than 64 KB gives an error in a formula. Dates outside years 1…9999 are treated as empty.
- **Formulas.** A reference to a value with an error reads as empty: the error does not propagate. `today()` refreshes on open and every 15 minutes, not exactly at midnight. The result type is saved with the formula: if it changes because a source changed type, the formula shows an error until saved again. No syntax highlighting or autocompletion; lists of properties and functions are available for insertion. A formula chain or rollup chain longer than 16 steps is not fully recalculated, without a message; with duplicate property names `prop("Name")` takes the first; deleting a property recalculates formulas of the whole database.
- **Person.** The “Person” type cannot be changed to another type or back. CSV import does not recognise people. Deleting a person removes filter rules in database views, but not in inline views on pages: such a rule simply matches nothing. The people directory is in insertion order. Values are not in ⌘K search.
- **Files & media.** The type cannot be changed. A file opens in its default app straight from storage: if that app overwrites it, the attachment changes too. Files are added to a cell through the menu, not by dropping. A file removed from a cell stays in storage and in backups. CSV import does not restore files. “Empty”/“Not empty” are the only filters.
- **Manual order.** Does not apply in inline views on a page (records there are in insertion order). One record at a time; the list does not auto-scroll while dragging.
- **Column width.** Tables only. Version 1.1 and older drops column widths when saving the view; record data is not affected.
- **Undo in databases.** Undoes values, bulk changes and record moves. Not undone with ⌘Z: a record title in the table (the field has its own text undo while focused), edits in the property card on a record page, creating and deleting records (deleted ones are in the trash), property and view changes. If the record was changed in another window between the edit and the undo, undo restores the value from before the edit. The undo stack is shared with the window's text fields, as usual on macOS.
- **Timeline.** At most 1,000 records on the scale across all groups; the scale extends while scrolling, but at its limit (8 chunks) it is rebuilt around the visible day. The position is remembered for database views but not for inline views. Manual order does not apply while sorted or in an inline view. Dependencies are a self-relation; arrows are drawn only between records currently on the scale. Create a dependency by dragging the dot at the right end of a bar or from the menu (the menu lists the first 100 records). Time of day shows on dates with time; at the “Hours” scale moves snap to 15 minutes, otherwise to whole days. The group header scrolls vertically with the bars. Version 1.1 does not show the Timeline tab but keeps it.
- **Block colour.** Text blocks only: images, files, tables and database views have no colour. A new block after Enter does not inherit the colour. Colour is not exported to Markdown (noted in the report). “Block colour” is in the context menu; the block handle has no separate menu.
- **Mentions.** A date shows the label from when it was inserted (“12 November 2026”), not “Today”/“Tomorrow”. A reminder is a local macOS notification: removing the mention does not cancel it, and it arrives only if the app is signed and notifications are allowed. ⌘Z of an old edit may bring back the previous page label in that block until the next rename. Two identical adjacent mentions of one page without a space merge. Renaming does not touch the text of a `[[` link labelled by hand (by design).
- **Bookmarks and embeds** (ADR-0011). “Link previews” is off by default: a bookmark then shows only the address and an embed opens in the browser. An embed shows as a card and opens in a window, not inline (ADR-0005). The preview does not refresh by itself: use “Refresh preview” in the context menu. The preview image stays in storage after the bookmark is deleted, like other attachments until cleanup. Sites that need sign-in or JavaScript for metadata give only the address. Versions before M12 show these blocks as “not supported” but keep them.
- **Synced block** (ADR-0012). The content of one original is shown once per page: a second copy of the same original, and a copy on the original's own page, show only a label. Copy content is indented one level (Notion's frame has no indent). Deleting an original does not offer to unsync copies — they show “Original unavailable”. Markdown export of a copy writes a note; content is exported only with the original. Search and backlinks find the text on the original's page. Versions before M12 show the original and copies as “not supported”; the original's children are visible on its page.
- **Live inline databases.** The height is set by hand (200–900 points) and does not fit the content automatically. The inline view keeps its own scrolling: the mouse wheel over it scrolls the table, not the page. A text selection on the page passes through the view as a single block.
- **Columns.** A mouse selection across fields becomes a whole-block selection only on mouse-up: while dragging, the text of the current field is highlighted. Such a selection can be copied, cut and deleted but not formatted (formatting works within one field). Find on page (⌘F) searches each field separately. Columns cannot be nested. Versions before M13 show the row and columns as “not supported”, with their blocks nested beneath.
- **Peek.** One page in Peek at a time; a page already open in full does not open in Peek. Opening the full page closes Peek. Peek and the main page each have their own ⌘Z.
- **Comments.** Threads are shown in a panel (the “Comments” button above the text), not in the margin. A text comment is attached to its ranges by a mark: if the text is deleted, the thread stays in the panel with its quote. Editing your own comment is not supported — delete and write again. Markdown export does not include comments (noted in the report).
- **Black & White theme.** Colours, font and sizes as in Notion (text 16, headings 30/24/20, width 708, sidebar 14), without Notion's logo, name or illustrations. New text sizes apply to a page the next time it is opened after switching themes.
- **Updates** (ADR-0014). Authenticity is checked only against the checksum from the same release (the build has no Developer ID signature); the publisher signature of the app and of plugin installers is not checked — there is nothing to pin while builds are ad-hoc signed. If the app's folder is not writable, the installer offers to download the image manually. A test copy with another identifier does not look for updates.
- **Extensions** (ADR-0015). Two kinds work for now: theme and app icon. The icon changes in the Dock while the app runs; Finder keeps the standard one.
- **Section order.** Drag a section by its title; a line shows whether it lands above or below the target. The list does not auto-scroll while dragging.
- **Page password** (ADR-0017). This is an app lock, not encryption: `workspace.sqlite`, backups and exports are readable without the password, and versions before 1.4 open such pages without it. Titles of locked pages stay visible in the sidebar, favourites, links and mentions. A synced-block copy of content from a locked page shows the text on other pages. A live inline database on a page that is already open stays visible after “Lock Now” until the page is opened again. An unlocked lock stays open until the display sleeps, the session locks or the app restarts, not on a timer.
- **AI** (ADR-0016, ADR-0018). Off by default; requests are paid and go to the chosen provider. Batches, automatic model fallback on refusal, prompt caching, answer depth and cost estimates are Claude-only. Other providers depend on the model: without tool support the chat answers without searching or editing pages; DeepSeek and Groq take no images; PDFs go only to Claude, OpenAI and OpenRouter (otherwise a note replaces the file). The agent sets text, numbers, dates, checkboxes, links, options, people and relations; formulas, rollups and timestamps are computed and files are added by hand. AI properties fill text, numbers, dates, checkboxes, links and options; for select and multi-select AI may add new options — up to 10 per fill (can be turned off in Properties); status uses existing options only. Applying a proposal goes page by page through the editor rather than one transaction across pages. After every new ad-hoc build macOS may ask for keychain access to the key.
- **Updating from older versions.** In 1.3.0–1.4.1 the updater timed out (“The request timed out”): install the latest `.dmg` from the Releases page manually once. In 1.4.2–1.5.0 the install can stop at “Checking and installing” because the update window blocks quitting: force-quit MindNotes (⌥⌘⎋), and the prepared update installs and relaunches by itself. Both are fixed from 1.5.1 on.

- **Browser clips** (ADR-0019). MindNotes downloads images from other sites in a clip itself; images served over plain http, behind a site login, larger than 8 MB or on a site name that resolves to a non-public address stay links. This does not protect against DNS rebinding (the name resolving differently between the check and the connection). Limitations of Web Clipper itself (Safari and Chrome installation, article extraction) are listed in [its repository](https://github.com/Slipcast-dev/MindNotes-WebClipper#known-limitations).
