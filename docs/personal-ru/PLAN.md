# План MindNotes

Требования: исходное ТЗ от 06.11.2026 и задание на функции Notion (этапы M10–M14). Отклонение от ТЗ (решение заказчика, ADR-0009): только Apple Silicon и macOS 26.

## Этапы

| Этап | Результат | Состояние |
|---|---|---|
| M0–M8 | Основа, редактор, базы и представления, шаблоны, перенос данных, история, выпуск 1.0 | Готово |
| M9 | Связи, свёртки, формулы, «Создано»/«Изменено» | Готово, выпуск 1.1 |
| M10 | «Человек», «Файлы и медиа», ручной порядок, ширина столбцов, ⌘Z в базе | Готово |
| M11 | Хронология | Готово |
| M12 | Цвет блока, `@`-упоминания, Bookmark, Embed, Synced block (`M12_PLAN.md`) | Идёт: цвет блока готов, выпуск 1.2 |
| M13 | Колонки и живые встроенные представления, как в Notion | Сначала ADR |
| M14 | Сворачиваемый сайдбар, действия в дереве, Peek, комментарии | Не начат |

## Правила на каждом этапе

- Результат — в `STATUS.md`, проверки и ручные списки — в `TEST_REPORT.md`, ограничения — в `KNOWN_LIMITATIONS.md`, приёмка — строкой в `ACCEPTANCE.md`.
- Отступление от ADR-0005 (единый `NSTextView`) и новые зависимости — только через ADR.
- Миграции схемы только добавляют, перед каждой — проверенный снимок.
- Все строки интерфейса через `L(...)` с переводом на английский.
- Корзина, дублирование, шаблоны, экспорт, поиск и резервная копия учитывают каждую новую сущность.
- Перед коммитом крупной функции — ревью; push и выпуски — только по поручению заказчика.
