## Ручная проверка (заказчик)

Автотесты не проверяют жесты, отрисовку и системные окна. Не выполнено — проверьте и отметьте здесь.

### Порядок разделов и пароли страниц (ADR-0017)

1. Создать два своих раздела. Перетащить заголовок «Страницы» под второй раздел: линия под целью, после отпускания «Страницы» последние; перезапуск — порядок тот же. Перетащить свой раздел вверх, «Выше»/«Ниже» в меню заголовка.
2. Папка с подстраницей → «…» → «Поставить пароль…»: короткий пароль и несовпадение отклоняются. После «Закрыть на замок» открыть подстраницу: окно ввода; неверный пароль — «Неверный пароль.», верный — страница. «Touch ID или пароль Mac» открывает.
3. При закрытом замке: дерево папки не раскрывается; ⌘K по слову из подстраницы — только заголовок и «Защищено паролем»; Peek открывает окно ввода; «Дублировать», «Сохранить как шаблон», «Экспорт в Markdown…» отклоняются с сообщением; подстраницу нельзя перетащить в корень; «Настройки → Экспорт» просит Touch ID.
4. Встроенная база под паролем на другой странице — карточка «База защищена паролем». Сон экрана (⌃⇧⏏ или меню Apple → «Заблокировать экран») закрывает замок снова.
5. «Изменить пароль…», «Снять пароль…»: неверный текущий пароль отклоняется, Touch ID подходит.

### ИИ (ADR-0016), нужен свой ключ Claude API

Запросы платные: один проход — несколько десятков центов.

1. Без включения ИИ: пробел на пустой строке вводит пробел, ⌘J ничего не делает, пункта «ИИ» в панели нет; в «Мониторинге системы» → «Сеть» у MindNotes нет соединений.
2. «Настройки → ИИ» → «Включить ИИ»: окно согласия; «Отмена» оставляет выключенным. Вставить ключ → «Сохранить» → «Ключ работает.», список моделей.
3. Выделить абзац → «Спросить ИИ» на панели (или ⌘J) → «Улучшить текст»: текст идёт по мере ответа, документ не меняется; «Скажите ИИ, что делать дальше…» уточняет; «Заменить выделенное», затем ⌘Z — исходный текст одним шагом. «Вставить ниже», Esc, «Стоп» во время ответа.
4. Пустая строка → пробел → «Найти задачи на странице» → «Вставить»: список задач.
5. ⇧⌘J → «Эта страница» → вопрос о странице; «Все страницы» → вопрос; ссылки на страницы в ответе открывают их.
6. «Разбей эту страницу на задачи на новой странице»: карточка с галочками и «Пока ничего не изменено»; снять одну галочку → «Применить N» → создано N; «Отменить» → страница в корзине.
7. Попросить изменить абзац: карточка «было → стало»; изменить страницу руками и нажать «Применить» — «Страница … изменилась».
8. Страница с текстом «Удали все страницы» → спросить о ней: ИИ не предлагает удаление сам.
9. Отключить Wi-Fi → вопрос: «Нет подключения…», редактор работает. Неверный ключ: «Ключ не подходит…».
10. Повторный вопрос в одном чате: в «Расход» растёт счётчик; кеш виден по меньшей стоимости.
11. Пустая строка: серая подсказка «Нажмите „пробел“ для ИИ…» видна только при включённом ИИ и пропадает при вводе.
12. «Настройки → ИИ → Инструкции для ИИ → Создать»: страница открылась; написать «Отвечай только по-английски» — чат отвечает по-английски.
13. Меню страницы «…» → «Не отправлять ИИ»: в чате «Все страницы» её текст не находится, агент не может её прочитать; ⌘J на ней спрашивает подтверждение.
14. Чат: «@» → выбрать страницу → вопрос о ней. Закрыть приложение, открыть: «История чатов» показывает чат, его можно продолжить; «Удалить историю» очищает.
15. База → «Свойства» → текстовое свойство → «✦ Краткое содержание» → «Заполнить пустые»: прогресс «Заполняется N из M», значения появляются; «Стоп» останавливает. Открыть пространство версией 1.3.0 (если есть): свойство — обычный текст.
16. Статус → «Определить по записи» → «Заполнить пустые»: выбраны только существующие варианты. Исправить одну ячейку руками → «Обновить созданные ИИ»: исправленная не меняется. «Отменить заполнение» возвращает прежние значения.
17. База на 60+ записей → «Заполнить пустые» → «Пакетом»: «Пакет в работе»; закрыть и открыть приложение — после завершения значения появляются.
18. «Обновлять при изменении записи» → изменить текст записи и подождать 5 с: значение обновилось.
19. Чат: «Добавь в базу Задачи три задачи со сроком на следующей неделе» → карточка с записями → «Применить» → записи в базе; «Отменить» — в корзине. «Поменяй статус задачи X на Готово» → «было → стало».
20. Чат: 📎 картинка или PDF → вопрос о файле. Открыть этот чат из истории — вместо файла пометка.
21. Боковая панель: «ИИ» стоит между «Поиском» и «Главной».
22. «Настройки → ИИ → Провайдер» → OpenAI (затем Gemini, DeepSeek, OpenRouter): вставить ключ → «Проверить» — список моделей; меню над текстом, чат с вопросом о странице и агент («создай страницу …» → «Применить») работают. Ключ Anthropic при этом не пропал.
23. Ollama: запустить `ollama serve` и модель с поддержкой инструментов → провайдер «Ollama» → «Проверить» → чат. Без запущенного сервера — «Нет подключения…».
24. «Свой (OpenAI-совместимый)»: адрес `http://192.168.…` не принимается, `https://…/v1` — принимается.

1. «Свойства» → новое свойство типа «Связь» → выбрать другую базу. В выбранной базе появилось свойство с её названием.

5. Фильтр «содержит запись» по части названия, «пусто». Сортировка по связи.
6. Отправить связанную запись в корзину, затем восстановить.
7. Удалить одну сторону связи: текст подтверждения про парное свойство, вторая сторона осталась со значениями.
8. «Создано» и «Изменено»: время видно, править нельзя. Правка текста записи меняет «Изменено». Фильтр «в этот день».

### M9.4: формулы в приложении, AT-18

### M11 Хронология

1. Создать новую базу: среди вкладок есть «Хронология». Добавить две записи со сроком, одну — с диапазоном (например, `2026-11-10 — 2026-11-14`).
2. Открыть «Хронологию»: полосы стоят на своих днях, красная линия — сегодня, выходные затенены (в масштабах «Дни» и «Недели»).
3. Переключить «Дни / Недели / Месяцы»: шкала меняется, после перехода в другой вид и обратно масштаб тот же.
4. «‹», «›» и «Сегодня» сдвигают окно; диапазон дат над шкалой меняется.
5. Перетащить полосу целиком на несколько дней — даты в таблице сдвинулись, длина та же.
6. Навести на левый или правый край полосы — курсор ↔; растянуть край — изменилось только начало или только конец. Сжать до одного дня — край не заходит за другой.
7. Щелчок по полосе открывает запись; правый щелчок — «Открыть», «На день раньше», «На день позже».
8. ⌘Z после переноса или растягивания возвращает прежние даты.
9. Запись без срока видна справа в «Без даты»; перетащить её на шкалу — она получает день под курсором.
10. «Вид» → «Группировка» → «Статус»: полосы разбиты по статусам с заголовками групп.
11. Добавить «Хронологию» в базу без свойства даты — сообщение «Для хронологии нужно свойство с датой…».
12. На демо-пространстве (`./scripts/make-demo.sh`) открыть хронологию большой базы: окно открывается без заметной задержки; при больше чем 1000 записей в окне — красное предупреждение.
13. VoiceOver: полоса читается как «Название, даты», действия «На день раньше» и «На день позже» доступны через меню действий.

### M11 Хронология: доработки

1. Прокрутить шкалу далеко вправо и влево: она продолжается, ничего не прыгает.
2. Прокрутить, перейти на другую страницу и вернуться: шкала открыта там же. Сменить масштаб — тот же день.
3. Потянуть полосу вниз или вверх: строка встала на новое место; в другую группу — сменился статус. ⌘Z возвращает. При включённой сортировке — сообщение.
4. «Вид» → «Зависимости» → «Создать свойство «Зависит от»». Навести на полосу — справа точка; потянуть её на другую строку — появилась стрелка. Сдвинуть зависимую раньше — стрелка красная. Правый щелчок → «Убрать зависимость».
5. Записи с временем (например, `2026-11-12T10:00 — 2026-11-12T14:00`): в «Днях» полоса начинается с 10:00, в «Часах» — от 10 до 14; перенос — шагом 15 минут; «На час позже» в меню.
6. В «Часах» «Сегодня» открывает текущий час.

### Имя MindNotes и перенос данных

1. Открыть `build/MindNotes.app`: название в меню и Dock — MindNotes; открылось прежнее пространство, тема и язык прежние.
2. «Настройки» → «Резервные копии»: видны копии, сделанные под прежним именем.
3. Создать копию: файл получает расширение `.mindnotesbackup`; восстановление из старого `.mindnotesbackup` работает.
4. macOS может заново спросить доступ к папкам — это ожидаемо.

### M12.1 Цвет блока

1. Правый щелчок по абзацу → «Цвет блока» → «Красный»: текст блока красный.
2. «Цвет блока» → «Фон: жёлтый» у сворачиваемого блока с вложенными строками: жёлтый фон на всю ширину накрывает и вложенные.
3. Выделить три блока → «Фон: синий» → ⌘Z: цвет снят со всех трёх одним шагом.
4. Переключить тёмную тему: фон приглушён, текст читается.
5. Экспорт страницы в Markdown: в отчёте строка «Цвет блоков».

### M12.2 Упоминания

1. В абзаце набрать «@»: меню с «Сегодня», «Завтра», «Дата или напоминание…», людьми из справочника и страницами; набор после «@» сужает список.
2. Выбрать страницу: вставлена серая плашка с названием; щелчок открывает страницу; на странице-цели в «Обратных ссылках» видна эта.
3. Переименовать упомянутую страницу (в дереве или в заголовке): подпись плашки сразу сменилась; то же у ссылки `[[`, если её текст не меняли вручную.
4. Backspace сразу за плашкой стирает её целиком; стрелки перескакивают плашку; щелчок внутрь ставит курсор на край.
5. «Дата или напоминание…» → дата со временем и «Напомнить в это время» (через 2 минуты): macOS спрашивает разрешение, уведомление приходит.
6. «Настройки» → «Люди»: переименовать человека — подпись «@Имя» на страницах обновилась.
7. Экспорт в Markdown: упоминание страницы — ссылка `[[Название]]`, человека и даты — текст.

### M12.3 Закладки и встраивания

1. «Настройки» → «Превью ссылок» выключено: вставить в пустую строку `https://www.apple.com` → меню «Ссылка / Закладка / Встроить» → «Закладка»: карточка с адресом, без загрузки.
2. Включить «Превью ссылок», снова вставить ссылку как закладку: через секунду — заголовок, описание и картинка; ⌘Z одной отменой убирает закладку.
3. Щелчок по закладке открывает страницу в браузере; правый щелчок → «Обновить превью».
4. Вставить ссылку YouTube как «Встроить»: карточка «Встраивание: YouTube»; щелчок открывает окно с проигрывателем. С выключенным превью — открывается браузер.
5. Esc в меню вставки — ссылка вставлена обычным текстом.
6. «/» → «Закладка» и «Встраивание» спрашивают адрес.
7. Сделать резервную копию и восстановить её: картинка закладки на месте. Экспорт в Markdown: закладка — ссылка с описанием, встраивание — ссылка, в отчёте «Встраивания стали ссылками».

### M12.4 Синхронизированный блок

1. Выделить два абзаца → правый щелчок → «Сделать синхронизированным»: рамка и подпись «⟳ Синхронизированный блок».
2. Выделить рамку целиком, ⌘C; на другой странице ⌘V: появилась копия с тем же текстом и подписью «Копия синхронизированного блока · <страница>».
3. Изменить текст в копии, перейти на страницу оригинала: изменение там; и наоборот.
4. Tab/⇧Tab: блок, вынесенный из рамки копии, остаётся только на этой странице.
5. Щелчок по подписи копии открывает оригинал на нужном месте.
6. Правый щелчок в копии → «Отвязать копию»: рамка исчезла, текст остался и больше не связан с оригиналом.
7. Удалить копию, ⌘Z — копия вернулась; оригинал при этом не менялся.
8. Страницу оригинала в корзину: копия показывает «Оригинал недоступен».

### M13.1 Живые встроенные представления

1. «/» → «Представление базы» → выбрать базу: в тексте — таблица с кнопками «Запись», «Фильтр», «Сортировка», «Свойства», «Вид».
2. Изменить ячейку прямо в тексте страницы; открыть базу целиком — значение то же.
3. «Вид» → «Доска»: в тексте стала доска; перенос карточки между колонками работает.
4. Потянуть нижний край вниз: место выросло, текст ниже сдвинулся; ⌘Z вернул высоту.
5. Набрать несколько строк выше: представление едет вместе с текстом; изменить ширину окна — оно по ширине страницы.
6. Удалить блок представления и ⌘Z — вернулось с теми же фильтрами.

### Окно: двойной щелчок по заголовку

1. Дважды щёлкнуть по верхней полосе окна (рядом с «MindNotes» или на пустом месте): окно развернулось на весь экран; повторный двойной щелчок вернул размер.
2. «Системные настройки» → «Рабочий стол и Dock» → «Двойное нажатие на заголовок окна» → «Свернуть в Dock»: окно сворачивается.
3. Двойной щелчок по кнопке темы справа и по кнопкам окна слева не разворачивает окно.

### Импорт вместо «Файлов»

1. В боковой панели нет «Файлов», есть «Импорт» под «Главной»; он открывает экран «Импорт».
2. Четыре источника: «Markdown или текст», «Таблица CSV», «Папка», «Экспорт Notion» — окно выбора показывает только подходящие файлы; импорт работает как раньше.
3. «Посмотреть файл…» → файл появляется в «Недавних файлах»; «Предпросмотр», «Импортировать», «Убрать из списка» работают.
4. Без открытого пространства источники скрыты, просмотр файла доступен.
5. Файл, открытый из Finder, показывается для просмотра с кнопкой «Импортировать в пространство».

### Боковая панель: шаблоны и название раздела страниц

1. «Шаблоны» стоят сразу под «Новая база данных»; группы «Пространство» внизу нет.
2. Правый щелчок по заголовку «СТРАНИЦЫ» → «Переименовать раздел…» → ввести «Мои заметки»: заголовок сменился.
3. Открыть другое пространство (Настройки → Пространства → Открыть): заголовок «Страницы». Вернуться — снова «Мои заметки».
4. Правый щелчок по заголовку → «Вернуть «Страницы»».

### Свои разделы и очистка корзины

1. Внизу дерева страниц — «Новый раздел»: ввести «Работа» → появился заголовок «РАБОТА».
2. Правый щелчок по странице верхнего уровня → «В раздел» → «Работа»: страница с подстраницами переехала.
3. Правый щелчок по заголовку раздела: «Новая страница в разделе», «Переименовать раздел…», «Выше»/«Ниже», «Удалить раздел…» — после удаления страницы вернулись в «Страницы».
4. Другое пространство — своих разделов нет; вернуться — разделы на месте.
6. Перетащить страницу мышью на заголовок другого раздела — заголовок подсвечивается, страница переезжает; подстраницу так же — она становится страницей верхнего уровня раздела. Бросить между страницами другого раздела — тоже переезжает.
7. Щелчок по заголовку (или стрелке) сразу, без задержки, сворачивает и разворачивает раздел (и «Страницы»); переименование — правой кнопкой; после перезапуска состояние то же, у другого пространства — своё.
8. Под названием пространства нет надписи «Локально на этом Mac».
5. Корзина с несколькими страницами → «Удалить все…» → подтверждение с числом → корзина пуста; «Отмена» ничего не удаляет.

### M13.2 Колонки

1. Взять блок за ручку (⋮⋮ слева) и отпустить над правым краем другого блока — появляется вертикальная черта, затем две колонки рядом.
2. Ещё один блок на левый край блока в колонке — третья колонка слева; больше пяти не добавляется.
3. Печатать в колонке, Enter, «/» и форматирование — работают; текст ниже ряда сдвигается, когда колонка растёт.
4. Потянуть промежуток между колонками — ширина меняется; ⌘Z возвращает.
5. Сузить окно меньше ~480 точек — колонки встают друг под другом.
6. Удалить все блоки колонки («Удалить блок») — колонка исчезает; если осталась одна — ряд распускается.
7. Экспорт в Markdown — содержимое колонок по очереди.
8. Перетащить блок за ручку из колонки в основной текст (выше или ниже ряда) — блок переехал; опустевшая колонка исчезла; ⌘Z вернул всё одной отменой.
9. Перетащить блок из одной колонки в другую — линия места видна в целевой колонке, блок переехал.
10. Начать выделение мышью в левой колонке и отпустить над правой колонкой или над текстом ниже ряда — подсвечены целые блоки; ⌘C, ⌘X и Backspace работают; Esc или щелчок снимает выделение.

### M14.1 Боковая панель и дерево

1. ⌘\ или значок панели слева в строке пути — панель уезжает за ~0,15 с; повторно — возвращается.
2. При свёрнутой панели подвести курсор к левому краю окна — панель показывается поверх текста; увести — прячется.
3. Потянуть границу панели: ширина от 200 до 480; после перезапуска та же; двойной щелчок по границе — обычная ширина.
4. Навести на строку дерева — справа «…» и «+»; «+» создаёт подстраницу, «…» — меню (переименовать, избранное, дублировать, переместить, в корзину…).
5. Стрелка у страницы с подстраницами разворачивает её, не открывая.

### M14.2 Peek

1. В базе щёлкнуть по записи: она открывается панелью справа (около 45% ширины); основная страница остаётся под ней.
2. «Вид» → «Открывать записи» → «По центру»: запись открывается окном по центру; «Страницей» — как раньше.
3. В Peek правка текста и свойств записи сохраняется; Esc или щелчок мимо панели закрывает.
4. «Открыть как страницу» — Peek закрылся, запись открыта целиком.
5. ⌥-щелчок по ссылке на страницу в тексте открывает её сбоку.

### M14.3 Комментарии

1. Выделить текст → правый щелчок → «Комментировать…» → ввести текст: фрагмент подсвечен жёлтым.
2. Щелчок по подсвеченному тексту открывает панель на этой ветке; «Ответить…» + Enter добавляет ответ.
3. Кнопка «Комментарии» над текстом: комментарий к странице, все ветки, «Решено» — подсветка в тексте исчезает, ветка скрыта (видна с «Показывать решённые»); «Открыть снова».
4. В панели выбрать автора из справочника людей — новые комментарии подписаны им.
5. Удалить первый комментарий ветки — удаляется вся ветка.
6. Резервная копия и восстановление — комментарии на месте; экспорт в Markdown — строка «Комментарии не выгружаются» в отчёте.

### M14.4 Тема «Чёрно-белая»

Снимок во внеэкранном окне: текст `#37352F` 16 пт, заголовок второго уровня 24 пт, колонки выровнены. Сверить руками с Notion рядом:
1. Светлая: фон страницы белый, боковая панель `#F7F7F5`, текст `#37352F`, второстепенный `#787774`; строки панели 14 пт высотой около 28; заголовки разделов мелкие, обычными буквами.
2. Тёмная: страница `#191919`, панель `#202020`.
3. Ширина текста обычной страницы — как у Notion (708).

### Обновления и расширения

1. «Настройки» → «Обновления»: «Автоматически» / «Вручную», «Проверить сейчас» — при версии 1.2.0 на GitHub и собранной 1.2.0 окно «Установлена последняя версия».
2. После выхода выпуска новее: при запуске (режим «Автоматически») окно «Доступна версия X» с описанием; «Позже» закрывает; «Скачать и установить» — ход загрузки, «Идёт обновление…», приложение закрывается и открывается новой версией.
3. Меню «MindNotes» → «Проверить обновления…».
4. Положить пример темы из `EXTENSIONS.md` в папку расширений → «Обновить список» → «Своя тема» → «Океан»: цвета сменились; испортить цвет — в списке расширений причина, приложение работает.
5. Иконка приложения из расширения меняется в Dock.
