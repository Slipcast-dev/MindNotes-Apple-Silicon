# Статус

Репозиторий: `Slipcast-dev/MindNotes-Apple-Silicon`, ветка `personal-ru`. Выпуск: **MindNotes 1.6.0** (метка `v1.6.0`, страница Releases, 13.11.2026) — календарь, синхронизация с Календарём и Напоминаниями macOS, ИИ для календаря, исправления по аудиту. Web Clipper выпускается отдельно (метки `webclipper-v…`). Из 1.5.1 и новее приложение обновляется само; из 1.4.2–1.5.0 установка может остановиться на «Проверка и установка» — тогда завершите MindNotes принудительно; из 1.3.0–1.4.1 — один раз из `.dmg`. Только Apple Silicon, macOS 26 (ADR-0009). Схема пространства: v10. Проверки — `TEST_REPORT.md`, приёмка — `ACCEPTANCE.md`, ограничения — `KNOWN_LIMITATIONS.md`.

## Что умеет приложение

- **Пространство и редактор.** SQLite с миграциями и снимком перед каждой; страницы и подстраницы; блочный редактор на едином `NSTextView` (ADR-0005): все типы блоков, форматирование, Markdown-сокращения, меню «/», перетаскивание и вложенность блоков, ссылки на блоки; цвет блока (текст или фон с вложенными); колонки — бросок блока на край другого блока, ширина тянется, на узком окне колонки друг под другом; `@`-упоминания страниц, людей и дат с локальным напоминанием — неделимые, подпись следует за переименованием; синхронизированный блок — оригинал и копии на других страницах, правка в любом месте меняет все (ADR-0012).
- **Боковая панель.** Сворачивается (⌘\, кнопка в строке пути, показ при наведении на левый край), ширина 200–480 тянется; у строк дерева при наведении «+» и «…». Свои разделы страниц (как «Страницы», схема v9) с перетаскиванием за заголовок, переименуемый раздел «Страницы», «Импорт» и «Шаблоны» рядом с кнопками создания.
- **Навигация.** Поиск ⌘K (FTS5), ссылки `[[`, обратные ссылки, избранное, теги, назад/вперёд, значок и обложка страницы, шаблоны (ADR-0008).
- **Вложения.** Картинки, файлы, видео с проигрывателем в окне; закладки с превью страницы и встраивания (YouTube, Vimeo, Figma, Google Maps, любая страница) в отдельном окне. Сеть — только для них, по действию пользователя и при включённом «Превью ссылок» (ADR-0011).
- **Базы данных.** Запись — страница со свойствами. Типы: текст, число, выбор, статус, дата с диапазоном и поясом, флажок, ссылка, связь (двусторонняя), свёртка, формула (свой язык, 38 функций), «Создано», «Изменено», «Человек» (справочник людей), «Файлы и медиа». Виды: таблица (ширина столбцов), доска, список, календарь, галерея, хронология (часы/дни/недели/месяцы, перенос и растягивание полос, зависимости, время суток). Фильтры с группами И/ИЛИ, сортировка, группировка, ручной порядок, массовое изменение, ⌘Z. Встроенные представления на страницах — живые: таблица, доска и другие виды прямо в тексте, с правкой ячеек и изменяемой высотой.
- **Комментарии.** К выделенному тексту и к странице, ветки с ответами, «Решено», автор из справочника людей (схема v10).
- **Данные.** Корзина (с «Удалить все»), история версий, резервные копии вручную и автоматически (`.mindnotesbackup`, ADR-0003), восстановление. Импорт Markdown, CSV, папок и экспорта Notion (со связями) — один экран «Импорт» с недавними файлами; экспорт в Markdown и CSV.
- **Обновления** (ADR-0014): проверка выпусков на GitHub автоматически или вручную, окно «Доступна версия», загрузка со сверкой SHA-256, установка и перезапуск.
- **Расширения** (ADR-0015, `EXTENSIONS.md`): свои темы и иконки приложения из папки расширений; код не исполняется.
- **Плагины** (ADR-0019, `EXTENSIONS.md`): пакеты `.mnplugin` с разрешениями, локальный API только для расширений браузера на этом Mac, автоподключение, обновления плагинов из выпусков. **Web Clipper** (`Plugins/WebClipper/`): статьи, выделенное, закладки, скриншоты и картинки из Chrome и Safari; ставится установщиком `MindNotes Web Clipper.app`, выпускается отдельно `scripts/release-webclipper.sh`. Плагины обновляются сами по своему расписанию (при запуске и раз в сутки), без вопроса — если не просят новых разрешений; в карточке плагина «Проверить обновления» и «Обновлять автоматически». Расширение подстраивается под возможности MindNotes (`features`), а не под её версию.
- **ИИ-ассистент** (ADR-0016, необязательный, выключен по умолчанию): «Спросить ИИ» над выделением и ⌘J, пробел на пустой строке, подсказка на пустой строке, чат ⌘L с вопросами о странице и пространстве, упоминанием страниц через «@» и историей, страница «Инструкции для ИИ», «Не отправлять ИИ» для страниц, ИИ-заполнение свойств баз (с отметкой «создано ИИ», отменой, автообновлением и пакетами), файлы в чате, агент с инструментами страниц и баз, который сначала предлагает изменения и применяет их только по «Применить». Провайдеры на выбор (ADR-0018): Anthropic, OpenAI, OpenRouter, Gemini, DeepSeek, Mistral, xAI, Groq, локальные Ollama и LM Studio, свой OpenAI-совместимый адрес; ключи в Keychain.
- **Пароли страниц** (ADR-0017): замок интерфейса на страницу, запись, базу или папку — пароль, Touch ID или пароль Mac; поддерево, поиск, встроенные базы, копии, экспорт и ИИ закрыты.
- **Календарь** (1.6.0): день, неделя и месяц в стиле Календаря Apple, синхронизация записей баз с Календарём и Напоминаниями macOS, инструменты ИИ для календаря. Песочница проверок синхронизации `CalendarSyncLab` лежит рядом с репозиторием и в него не входит.
- **Имя и данные.** MindNotes, `local.personal.MindNotes`; настройки и копии прежней версии переносятся при первом запуске (ADR-0010).
