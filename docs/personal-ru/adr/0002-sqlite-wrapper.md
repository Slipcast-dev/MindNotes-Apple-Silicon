# ADR-0002. Своя тонкая обёртка над системным SQLite

Статус: принято, 06.11.2026.

Контекст: на машине разработки только Command Line Tools, поэтому `swift build` и Swift-пакеты недоступны; сборка идёт прямым вызовом `swiftc`. ТЗ требует минимум зависимостей и реального подключения пакетов к сборке.

Проверено: `import SQLite3` компилируется и линкуется при цели macOS 13; системная версия 3.39.5, `THREADSAFE=2`, FTS5 работает. `sqlite3_backup_*` проходит проверку типов на x86_64 и arm64.

Решение: тонкая обёртка в `Persistence/` без зависимостей.

Последствия: нет стороннего кода и лицензий; нужны тесты на время жизни statement и обработку ошибок. Версия SQLite зависит от macOS, поэтому код не использует возможности новее 3.39. При `THREADSAFE=2` одно соединение нельзя использовать из двух потоков: каждое соединение живёт на своей очереди.
