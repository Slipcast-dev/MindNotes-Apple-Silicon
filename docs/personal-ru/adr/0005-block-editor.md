# ADR-0005. Редактор страницы на едином NSTextView (TextKit 1)

Статус: принято по итогам прототипа M3, 06.11.2026. Ручная проверка живого ввода выполняется заказчиком.

## Варианты

- Отдельное поле на блок (временный редактор M2): нет выделения через блоки, копирования и системного поведения курсора, всё это пришлось бы писать вручную.
- Веб-редактор: другой стек, запрещён ТЗ без отдельного решения.
- **Единый NSTextView на страницу.** Выделение, IME, раскладки, emoji и VoiceOver работают системно. Сложность — согласование вида с моделью блоков.

## Решение

Текст вида — блоки через `\n`; перенос внутри блока — U+2028 в виде и `\n` в модели; длина в UTF-16 совпадает. Непонятный блок — один неделимый символ-вложение, его данные хранятся без изменений. Это же заглушка для таблиц и встроенных баз до их реализации.

Правка внутри одного блока выполняется штатно, модель догоняет вид в `textDidChange`. Всё, что пересекает границу блока, отклоняется в `shouldChangeText` и выполняется командой `replaceRange`; в текст вида вносится только изменившийся участок. Запись в базу никогда не трогает вид, поэтому выделение и прокрутка не сбрасываются. Составной ввод не меняет модель до завершения. Отмена только через `UndoStack`.

## Правила клавиш (FR-06)

| Клавиша | Условие | Результат |
|---|---|---|
| Enter | внутри блока | разделение; задача порождает задачу, заголовок — абзац |
| Enter | начало непустого заголовка | заголовок сдвигается вниз, над ним пустой абзац |
| Enter | пустая задача | задача становится абзацем |
| Enter | поверх выделения | выделение удаляется, блок разделяется |
| Shift+Enter | где угодно | перенос внутри блока |
| Backspace | начало блока не-абзаца | тип снимается, текст не меняется |
| Backspace | начало абзаца | объединение с предыдущим; с непонятным блоком не объединяется |
| Backspace | первый абзац документа | ничего |
| Delete | конец блока | следующий блок вливается; непонятный блок остаётся |
| Удаление выделения | строка целиком | остаётся следующий блок со своим типом и отметкой |
| Удаление выделения | всё | остаётся пустой абзац |

Непонятный блок удаляется только выделением или Backspace сразу после него; отмена его возвращает. Tab и Shift+Tab появятся вместе со списками (M4).

## Проверено

`tests/swift-notes/NativeEditorTests.swift` работает с настоящим `NSTextView`: ввод, составной ввод, команды, буфер обмена, отмена, случайный прогон 600 правок со сверкой вида и модели и полной отменой. Замер на 500 блоках (Intel i5-4288U, `-O`, без отрисовки): см. `TEST_REPORT.md`.

Критерий отказа — p95 ввода выше 50 мс или неустранимая поломка IME/Undo — не сработал.

## Последствия и ограничения

- Запасной вариант, сегментация страницы на несколько видов, понадобится, только если таблицы нельзя будет разместить внутри одного вида. Решение — в M4.
- Перетаскивание текста отключено до M4: штатное удаляет источник по устаревшему диапазону.
- Правки в нескольких диапазонах сразу отклоняются.
- Форматирование, вложенность и меню `/` — M4.
- Отметка задачи рисуется поверх текста и пока не доступна VoiceOver как отдельный элемент.
- Отключение Writing Tools задаётся по имени свойства, так как SDK 13.3 его не содержит; на macOS 15 не проверено.
