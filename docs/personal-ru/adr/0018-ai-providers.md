# ADR-0018. Несколько провайдеров ИИ

Статус: принято 12.11.2026 по просьбе заказчика. Дополняет ADR-0016 (там был только Anthropic).

## Решение

- **Провайдеры:** Anthropic (Claude), OpenAI, OpenRouter, Google Gemini, DeepSeek, Mistral, xAI (Grok), Groq, локальные Ollama и LM Studio, а также «Свой» — любой сервер с OpenAI-совместимым API по адресу, который вводит пользователь. Каталог — `Workspace/Domain/AIProviders.swift`; адреса клиент берёт только оттуда (проверка AT-15).
- **Один формат внутри.** История, инструменты и предложения агента по-прежнему хранятся в формате Anthropic Messages. Для OpenAI-совместимых провайдеров тело переводится в Chat Completions (`AIOpenAI.body`), а поток ответа собирается обратно в `AIAssistantTurn` (`AIOpenAIAccumulator`). Поэтому меню над текстом, чат, агент с подтверждением, ИИ-свойства и проверки не зависят от провайдера.
- **Различия провайдеров** заданы в каталоге: предел длины ответа, строгие схемы инструментов, `json_schema` или `json_object`, `additionalProperties` (Gemini его не принимает), изображения и PDF, счётчики токенов в потоке, `max_completion_tokens` у OpenAI. Неподдерживаемый файл заменяется пометкой, а не отправляется.
- **Адреса:** только https, либо http только на этот Mac (`localhost`, `127.0.0.1`, `::1`); без логина, параметров и фрагментов в адресе. Встроенные адреса не меняются; свой адрес — только у «Своего».
- **Ключи:** свой у каждого провайдера в Keychain; у Anthropic имя записи прежнее, сохранённый ключ не пропадает. Локальным серверам ключ не нужен.
- **Модель** выбирается у каждого провайдера своя: из списка `GET …/models` после «Проверить» или вводом названия.
- **Только у Anthropic:** пакеты Message Batches, `fallbacks`, `effort`, кеширование промпта и размышления. У остальных провайдеров ИИ-свойства заполняются сразу, по три запроса.
- **Согласие и предупреждения** называют выбранного провайдера; у локального сервера — «модель на этом Mac».

## Последствия

- Возможности моделей у провайдеров разные: модель без вызова инструментов не сможет работать агентом (ошибка запроса видна в чате), слабая модель может хуже соблюдать формат ответа. Ответ, не подходящий к схеме, не записывается.
- Названия моделей в каталоге — стартовые; актуальный список даёт «Проверить».
- Стоимость считается только для Claude; у остальных — счётчики токенов.
