# ADR-0003. Формат резервной копии — несжатый ustar

Статус: принято, 06.11.2026.

Варианты:
- Каталог-пакет: хрупок при переносе, обрезанность копии трудно распознать.
- ZIP: в Foundation нет записи; своя реализация сложнее (CRC32, ZIP64, центральный каталог).
- Вызов `/usr/bin/tar`: нет потоковых хэшей и контроля записей.
- Свой ustar: простой формат, читается штатным `tar` как запасной путь.

Решение: один файл `.grizzlybackup` — несжатый ustar, своя реализация. Файлы от 8 ГиБ — размер в base-256. `manifest.json` и `manifest.sha256` пишутся последними и служат признаком полноты.

Последствия: архив не сжимается (предположение: основной объём составляют уже сжатые вложения). Читатель обрабатывает недоверенный вход: только обычные файлы, белый список имён, отказ при лишних и повторяющихся записях; это покрывается отдельными тестами.
