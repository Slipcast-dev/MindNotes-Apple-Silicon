# ADR-0019. Плагины: пакет `.mnplugin`, разрешения и локальный API

Статус: принято 12.11.2026. Первый плагин — WebClipper (сохранение страниц из Chrome и Safari).

## Контекст

ADR-0015 разрешает только декларативные расширения (темы, иконки) и требует отдельного решения для плагинов, которые
исполняют код. Веб-клиппер — именно такой: его код работает в браузере, и ему нужен путь, по которому вырезка попадает
в открытое пространство.

## Решение

1. **Код плагина не исполняется в процессе MindNotes.** Плагин работает в своей среде: расширение браузера, отдельная
   программа, скрипт. С приложением он говорит только через **локальный API** и только в пределах **разрешений**,
   которые пользователь подтвердил при установке. Так ошибка или злой умысел в плагине не может испортить базу,
   прочитать закрытые страницы (ADR-0017) или ключ ИИ.

2. **Пакет плагина** — папка `Имя.mnplugin` (macOS показывает её как один файл):

   ```text
   WebClipper.mnplugin/
     manifest.json          # kind = "plugin"
     browser/chrome/        # компоненты, которые плагин ставит вне приложения
   ```

   ```json
   { "id": "minerva.webclipper", "name": "Web Clipper", "version": "1.0.0", "kind": "plugin",
     "api": 1,
     "permissions": ["pages.list", "pages.create", "assets.create", "tags.write", "pages.open"],
     "components": { "chrome": "browser/chrome" } }
   ```

   Пути компонентов — только внутри пакета. Незнакомое разрешение или более новый `api` — плагин помечается
   «требует более новой версии» и не включается.

3. **Установка**: двойной щелчок по `.mnplugin` или «Настройки» → «Расширения» → «Установить плагин…». Приложение
   показывает имя, версию и список разрешений; только после «Установить» пакет копируется в
   `Extensions/<id>.mnplugin` и включается. Удаление — в корзину Finder, вместе с отзывом всех подключений.

4. **Локальный API** — HTTP/1.1 + JSON только на `127.0.0.1:27183` (не на сетевом интерфейсе). Слушатель запущен,
   только пока включён хотя бы один плагин.
   - Запрос из браузера принимается только от страниц расширений (`chrome-extension://`, `safari-web-extension://`,
     `moz-extension://`). Обычный сайт не может отправить вырезку, даже если знает порт.
   - **Привязка клиента**: `POST /v1/pair` открывает в MindNotes вопрос «Разрешить?» с именем плагина и браузера.
     После согласия клиент получает случайный токен (32 байта); приложение хранит только его SHA-256. Каждый
     следующий запрос — с `Authorization: Bearer <токен>`; права — разрешения плагина, к которому привязан клиент.
     Подключения видны в настройках плагина и отзываются там же.
   - Ограничения: тело до 40 МБ, заголовки до 16 КБ, одно ожидание «Разрешить?» за раз.

   | Метод и путь | Разрешение | Что делает |
   |---|---|---|
   | `GET /v1/status` | — | версия приложения и API, открыто ли пространство, привязан ли токен |
   | `POST /v1/pair` | — | привязка клиента с согласия пользователя |
   | `GET /v1/targets` | `pages.list` | страницы и папки, куда можно сохранять (без закрытых, баз и записей) |
   | `POST /v1/clips` | `pages.create` (+`assets.create` для картинок, `tags.write` для тегов) | новая страница из вырезки |
   | `POST /v1/pages/<id>/open` | `pages.open` | показать страницу в MindNotes |

5. **Запись** идёт тем же путём, что импорт (`ImportTarget`): страница появляется целиком одним пакетом, картинки —
   управляемые вложения, ссылки — только безопасные схемы. Сохранять под закрытую страницу нельзя.

6. **Установщик и самонастройка** (дополнено 12.11.2026). Плагину с компонентами вне приложения нужен свой
   установщик-программа: пользователь открывает её, и дальше всё идёт само. Для Web Clipper это
   `MindNotes Web Clipper.app`: внутри пакет плагина и расширение Safari.
   - Установщик находит MindNotes и браузеры, открывает пакет плагина в MindNotes (вопрос о разрешениях — в MindNotes),
     затем ставит расширение в каждый браузер по очереди.
   - **Окно автоподключения**: после установки плагина с согласия пользователя или по кнопке «Подключить браузеры»
     MindNotes 10 минут разрешает фоновому запросу расширения (`{"silent": true}`) показать вопрос о подключении.
     Ключ выдаётся только после согласия: Origin расширения, id плагина и открытое окно аутентификацией не являются
     (их может назвать любое расширение или локальная программа). В окне — не больше одного вопроса на источник и трёх
     за окно; после отказа окно закрывается, новые вопросы откладываются на 30 секунд. Повторное открытие пакета той же
     версии окно не открывает и выключенный плагин не включает. Расширение само проверяет `GET /v1/status` (поле
     `pairing`) при установке, запуске браузера и раз в минуту. Вне окна тихий запрос получает отказ без вопроса;
     кнопка «Подключить» в расширении по-прежнему спрашивает пользователя.
   - Ограничения браузеров: Safari включает расширение только сам пользователь (одна галочка в настройках Safari,
     для ad-hoc сборки — ещё «Разрешить неподписанные расширения»); Chrome и браузеры на Chromium без магазина Chrome
     не дают программам ставить расширения, поэтому остаётся одно перетаскивание папки на страницу расширений.
     После публикации в Chrome Web Store установщик сможет писать файл `External Extensions`, и браузер сам предложит
     включить расширение.

7. **Выпуски и обновления** (дополнено 12.11.2026). Плагин живёт в репозитории приложения (`Plugins/<Имя>/`),
   но выпускается отдельно:
   - своя версия в `manifest.json` плагина, свой `CHANGELOG.md`; номер поднимается при каждом выпуске — по нему
     установщик и MindNotes понимают, что пора обновлять;
   - теги `<префикс><версия>` (поле `updates`, для Web Clipper — `webclipper-v`) рядом с тегами приложения `v1.2.3`;
     выпуск — образ установщика и `SHA256SUMS.txt`, в описании строка `<!-- minApp: X -->`;
   - выпуск плагина публикуется **не последним** (`--latest=false`): MindNotes ищет свои обновления по
     `releases/latest` (ADR-0014);
   - `minApp` необязателен (п. 9); если задан, скрипт не выпустит плагин раньше подходящей MindNotes;
   - обновление плагина — см. п. 9; расширение в браузере сверяет версию на диске и перезапускается само.
   - Отдельный репозиторий — когда плагины станут писать другие люди или у плагина появится свой цикл в магазинах;
     история переносится `git subtree split --prefix=Plugins/<Имя>`.

8. **Картинки с других сайтов** (дополнено 13.11.2026). Расширение не просит доступ ко всем сайтам: картинки
   самой страницы скачивает браузер, а картинки с других сайтов (CDN) расширение передаёт адресами
   (`remoteImages` в `POST /v1/clips`), и их скачивает MindNotes (`Shell/Network/ClipImageFetcher.swift`). Ограничения:
   только https и только публичные адреса — `localhost`, `.local`, частные и служебные IPv4, IPv6 и числовые
   записи вроде `0x7f.0.0.1` запрещены, в том числе после переадресации; без cookies; до 8 МБ на картинку и общий
   предел вырезки; тип определяется по первым байтам (PNG, JPEG, GIF, WebP), SVG не принимается. Не скачалось —
   в тексте остаётся ссылка на оригинал. Остаётся риск подмены DNS (публичное имя, указывающее на локальный адрес);
   он ограничен тем, что запрос — только GET картинки, а ответ принимается только как картинка.

9. **Независимые обновления** (дополнено 13.11.2026).
   - **Возможности вместо версий.** `GET /v1/status` отдаёт `features` (`clips`, `targets`, `openPage`,
     `remoteImages`, …). Расширение подстраивается под список: нет `remoteImages` — картинки с других сайтов
     остаются ссылками. Поэтому новая версия плагина работает со старой MindNotes, и `minApp` нужен только при
     несовместимом изменении (`api` растёт).
   - **Своё расписание.** MindNotes проверяет выпуски плагинов при запуске и раз в сутки, независимо от режима
     обновлений приложения. В карточке плагина всегда видны «Проверить обновления», «Обновлять автоматически»
     (у каждого плагина своё, по умолчанию включено) и время последней проверки.
   - **Доверенное обновление.** В выпуск кладётся `plugin-manifest.json` (его сумма — в `SHA256SUMS.txt`).
     MindNotes скачивает его до образа и сравнивает: тот же `id`, версия новее, API понятен, разрешений не больше,
     чем подтверждено. Тогда обновление ставится без вопроса (само — при «Обновлять автоматически», или по кнопке):
     образ сверяется по SHA-256, установщик заменяется, пакет копируется в папку расширений (включённость и
     подключения браузеров сохраняются), установщик запускается с `--update` без окна и обновляет файлы расширения.
     Новые разрешения — только по кнопке «Обновить» и через обычный вопрос с их списком.

10. **Свой репозиторий плагина** (подготовка, 13.11.2026). Поле `"repository": "владелец/имя"` в `manifest.json`
    плагина говорит MindNotes, где искать его выпуски; без поля — как раньше, в репозитории приложения. Принимается
    только имя по правилам GitHub (никаких адресов, хостов и путей), запрос — только на `api.github.com`. В карточке
    плагина видно, откуда берутся обновления. Скрипт выпуска публикует в репозиторий из поля, а с
    `MIRROR_TO_APP_REPO=1` — ещё и копию в репозитории приложения (там — не «последним»).

    **Переезд, когда он понадобится:**
    1. Выпустить MindNotes с поддержкой поля (сделано в коде; входит в ближайший выпуск после 1.6.2) и подождать,
       пока большинство обновится.
    2. Создать репозиторий плагина с историей: `git subtree split --prefix=Plugins/WebClipper -b webclipper`,
       отправить ветку в новый репозиторий. Перенести туда скрипты сборки и выпуска, копии `AppIcon-source.png`
       и `target.sh`, CI с Xcode (для расширения Safari).
    3. Договор об API — отдельным файлом (порт, пути, разрешения, `features`): в репозитории приложения оригинал,
       в репозитории плагина копия; тесты обеих сторон сверяются с ним вместо чужого кода.
    4. В `manifest.json` плагина указать `repository`. Первый выпуск оттуда — с `MIRROR_TO_APP_REPO=1`: его увидят
       и старые MindNotes (в репозитории приложения), а после установки они переключатся на новый репозиторий,
       потому что поле придёт в описании. Обновление остаётся доверенным: разрешения не меняются.
    5. Через пару выпусков убрать дублирование, затем `Plugins/WebClipper` из репозитория приложения; обновить
       README, STATUS и ADR.

11. **Системы** (13.11.2026). Плагин поддерживает macOS 15 Sequoia и новее независимо от минимума самой MindNotes:
    установщик и расширение Safari собираются с `PLUGIN_MIN_MACOS=15.0` (только Apple Silicon), расширение
    рассчитано на Safari 18+ и Chromium; новые возможности браузера используются только после проверки наличия.
    Установщик читает `LSMinimumSystemVersion` найденной MindNotes и, если она требует более новую macOS, говорит
    об этом прямо. Пока MindNotes требует macOS 26, плагин на macOS 15 ставить некуда: он заработает там вместе
    с переходом приложения (план — `MACOS15_PLAN.md`).

## Последствия

- Будущие плагины (импорт из других сервисов, экспорт, автоматизация) используют тот же пакет, разрешения и API;
  новые возможности — новые пути и разрешения, `api` растёт только при несовместимых изменениях.
- Сеть по-прежнему только в `Shell/Network/` (ADR-0011): слушатель — `LocalAPIServer.swift`.
- Разбор манифеста, запросов HTTP и вырезок — в `Workspace/Domain`, запись — в `ImportExport`; всё покрыто тестами без UI.
