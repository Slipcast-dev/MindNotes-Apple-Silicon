# ADR-0016. Необязательный ИИ-ассистент

Статус: принято 11.11.2026 по решению заказчика (`MindNotes/04_ТЗ_ИИ_ассистент.md`). Меняет FR-16 исходного ТЗ («без ИИ»).

## Контекст

Заказчик попросил ИИ по сценариям Notion AI: действия над выделенным текстом, ИИ на пустой строке, чат с вопросами о пространстве и агент, который создаёт и правит страницы. Требование: не нарушить приложение. Без ИИ всё должно работать как раньше, а агент не должен менять данные без согласия пользователя.

## Решение

- **Необязательный модуль, выключен по умолчанию.** Включается в «Настройки → ИИ» после окна согласия. Пока ИИ выключен, нет ни одного запроса, Keychain не читается, пробел и ⌘J работают как раньше, пункта «ИИ» в боковой панели нет.
- **Один провайдер:** Anthropic Messages API (`https://api.anthropic.com/v1/messages`, `anthropic-version: 2026-10-21`), модель по умолчанию `claude-opus-5-5`. Сторонних SDK нет (официального Swift SDK нет): клиент на `URLSession` в `Shell/Network/AIClient.swift`. Локальных моделей, embeddings, телеметрии и других провайдеров нет. Writing Tools по-прежнему отключены.
- **Ключ — только в Keychain** (`Shell/Network/AIKeychain.swift`, `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`). В базу, `UserDefaults`, резервные копии, экспорт и журналы он не попадает.
- **Слои.** Протокол, разбор SSE, инструменты, проверка ввода и правила подтверждения — `Workspace/Domain/AI.swift`, только Foundation, тестируется без сети. Интерфейс — `Shell/AI/`. Редактор получает два замыкания (`aiAvailable`, `onAIRequest`) и метод `applyAI`: правка идёт обычной командой `replaceRange` одной группой отмены. Проверка AT-15 следит, что сеть ИИ — только в своём файле и только при включённом ИИ.
- **Подтверждение.** Изменяющие инструменты агента (`create_page`, `append_blocks`, `update_block`, `move_to_trash`) ничего не пишут: они собирают предложение. Пользователь отмечает пункты и нажимает «Применить». Правка существующего и корзина всегда с вопросом; без вопроса можно разрешить только создание и добавление в конец. Окончательного удаления у агента нет. Если страница изменилась после предложения, оно не применяется.
- **Запросы.** Стриминг, `output_config.effort` всегда явно (над выделением `low`, в чате — из настроек), `tool_choice: auto`, строгие схемы инструментов с `eager_input_streaming`, кеш на системном промпте и последнем инструменте, `fallbacks: "default"` с beta `server-side-fallback-2026-07-01`. Без `temperature`/`top_p`/`top_k` и prefill. Ответ возвращается в историю целиком. Содержимое страниц передаётся как данные, системный промпт запрещает выполнять из него команды.
- **Без изменения схемы.** Скрытые от ИИ страницы, страница инструкций и история чатов (до 30 чатов, до 3 МБ) — ключи `workspace_meta`, поэтому входят в резервную копию. ИИ-свойство — обычное текстовое свойство с настройкой в `config_json.ai`: прежние версии сохраняют поле и показывают текст. Учёт токенов — в `UserDefaults` (только счётчики). Миграции нет, версия 1.3.0 открывает пространство как раньше.

## Последствия

- Применение предложения идёт по шагам через редактор страницы: каждая правка — обычная команда с отменой на своей странице. Общей транзакции на несколько страниц нет; «Отменить» в карточке возвращает всё по шагам (созданное — в корзину).
- Сборка подписана ad-hoc: после каждой новой сборки macOS может спросить доступ к ключу в Keychain.
- ИИ-свойство: настройка в `config_json.ai` (вид, запрос, `auto`), ответ по строгой схеме своего типа (у выбора — `enum` вариантов), отметки «создано ИИ» — отпечатки значений в `workspace_meta` (`ai_filled_<свойство>`): ручная правка меняет значение, отметка пропадает без перехвата правок. Больше 50 записей — по выбору пакетом через Message Batches (`/v1/messages/batches`, без beta-заголовка и `fallbacks`), ожидание переживает перезапуск (`ai_batches`).
- Агент получил `query_database`, `create_database_rows`, `update_properties`: значения строками по именам свойств, проверка до предложения; правка свойств — всегда с подтверждением.
- Файлы в чате — блоки `image`/`document`; в сохранённой истории их содержимое заменяется пометкой.
- Отличия от ТЗ ИИ — в `KNOWN_LIMITATIONS.md`.
