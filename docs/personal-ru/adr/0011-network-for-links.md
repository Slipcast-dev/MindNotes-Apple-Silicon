# ADR-0011. Сеть для закладок и встраиваний (M12)

Статус: принято заказчиком 11.11.2026 (вариант «б»); реализация — в M12.

До сих пор в приложении нет ни одного сетевого запроса (AT-15, проверка `tests/edition.test.cjs`). Bookmark и Embed без сети теряют смысл, поэтому заказчик выбрал ограниченный доступ:

- Запрос только по действию пользователя: вставка ссылки и выбор «Закладка» или «Встроить», либо «Обновить» в меню блока. Никаких фоновых запросов, телеметрии, обновлений и аккаунтов.
- Выключатель «Загружать превью ссылок» в настройках, **выключен по умолчанию**. Когда он выключен, закладка — просто ссылка с названием, которое вводит пользователь.
- Один GET к адресу из ссылки (только `https`), предел размера ответа и времени; из страницы берутся `og:title`, `og:description`, `og:image`. Картинка сохраняется вложением пространства и попадает в резервную копию; дальше закладка показывается без сети.
- Embed (YouTube, Vimeo, Figma, Google Maps, произвольный адрес): в тексте — карточка-превью, по нажатию — окно с `WKWebView` (как видео, ADR-0005 не меняется).
- Весь сетевой код — в одном файле оболочки; проверка AT-15 разрешает `URLSession` и `WKWebView` только в нём и следит, чтобы его вызывали только действия пользователя.
