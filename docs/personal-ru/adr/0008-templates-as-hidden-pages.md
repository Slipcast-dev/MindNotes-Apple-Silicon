# ADR-0008. Шаблон как скрытая копия страницы

Статус: принято, 07.11.2026.

FR-12 требует, чтобы правила копирования шаблона и дублирования страницы совпадали: новые UUID, внутренние ссылки переназначаются, внешние сохраняются, вместе с подстраницами, вложениями и значениями свойств.

Решение: шаблон хранит не отдельный формат, а настоящую копию поддерева в `pages` и `blocks`. Такие страницы имеют `deleted_at` без `trash_batch_id`, а таблица `templates` указывает на корень. Создание из шаблона и дублирование — одна функция `copySubtree`.

Следствия:

- Все живые запросы уже фильтруют `deleted_at IS NULL`, поэтому шаблон не виден в дереве, поиске, ссылках и таблицах. Корзина требует `trash_batch_id IS NOT NULL`.
- Смена типа свойства и удаление варианта обновляют и значения шаблона: запрос значений идёт по всем страницам свойства.
- Шаблон входит в резервную копию без дополнительной работы.
- Окончательное удаление базы забирает её шаблоны. Базу в корзине шаблон переживает.
- Сочетание «`deleted_at` без пакета» зарезервировано: новый код не должен считать его корзиной.

Отвергнуто: JSON с блоками и значениями. Пришлось бы заново реализовать переназначение ссылок, вложения и поддерево, и правила разошлись бы с дублированием.
