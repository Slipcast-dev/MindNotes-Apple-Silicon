# ADR-0014. Обновления приложения

Статус: принято 11.11.2026 по решению заказчика.

Заказчик попросил фоновую проверку обновлений с установкой и перезапуском. Это вторая сеть в приложении после превью ссылок (ADR-0011).

## Решение

- **Источник** — только выпуски репозитория `Slipcast-dev/MindNotes-Apple-Silicon` на GitHub: `GET https://api.github.com/repos/…/releases/latest`. Других адресов нет; телеметрии, аккаунтов и передачи данных пользователя нет — запрос без cookies, данные пространства не уходят.
- **Режимы** (настройки → «Обновления»): «Автоматически» — проверка при запуске и раз в сутки в фоне; «Вручную» — только по кнопке «Проверить обновления». По умолчанию — «Автоматически».
- **Найдено обновление** — окно «Доступна версия X» с описанием выпуска и кнопками «Скачать и установить» / «Позже». Без согласия ничего не скачивается.
- **Установка**: образ `MindNotes-X.dmg` скачивается во временную папку и сверяется по SHA-256 из `SHA256SUMS.txt` того же выпуска; не совпало — установка отменяется. Образ монтируется только для чтения, новая программа копируется рядом со старой, затем пространство записывается, приложение закрывается, небольшой сценарий заменяет пакет и запускает новую версию. Во время работы показывается «Идёт обновление…».
- **Сеть** — по-прежнему только в `Shell/Network/` (проверка AT-15 следит за этим).

## Последствия

Сборка подписана ad-hoc: проверка подлинности — только сверка суммы из того же выпуска (защищает от повреждения, не от подмены выпуска на GitHub). С подписью Developer ID можно добавить проверку подписи. Если приложение лежит там, куда нельзя писать, установка сообщает об этом и предлагает скачать образ вручную.
