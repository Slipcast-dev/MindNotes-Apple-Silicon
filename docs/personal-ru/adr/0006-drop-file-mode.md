# ADR-0006. Отказ от файлового режима; цель — функциональность Notion

Статус: принято решением заказчика, 06.11.2026. Заменяет ADR-0004. Отменяет FR-01 и AT-13 ТЗ v1.0 в части редактирования файлов.

Заказчик, проверив сборку, поручил убрать старый интерфейс и возможности исходного приложения и приблизить функциональность к Notion.

## Решение

Удалены: редактор файлов на диске, вкладки, две панели, поиск в файле, закладки, библиотека, теги, умные папки, вложения в файлах, темы, шрифты, эффект стекла, настройки типов файлов, обновления, патчи, Quick Look, просмотр архивов, старые Swift-тесты.

Раздел «Файлы» остаётся, как в макете: файл на диске можно посмотреть и импортировать как страницу. Сам файл не меняется. Файл из Finder только показывается.

Единое меню: правый клик, меню «Формат», панель при выделении и меню «/» строятся из одного списка `EditorAction`.

## Последствия

- Код исходного приложения доступен в git: метка `baseline-1.4.2`.
- Копирайт и уведомление о лицензии сохранены на экране настроек и в `LICENSE`.
- Порт Electron для Windows в личную сборку не входил; удалён из репозитория 11.11.2026 (ADR-0010).
- Обновлений нет: сборка обновляется вручную (FR-17).
- Импорт Grizzly-библиотеки (FR-14.1) не актуален без файлового режима; файлы импортируются по одному, пакетный импорт — M7.
