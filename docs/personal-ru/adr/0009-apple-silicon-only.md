# ADR-0009. Только Apple Silicon и macOS 26

Статус: принято, 07.11.2026, по решению заказчика. Заменяет требования ТЗ о macOS 13 и сборке для Intel, отменяет двухшаговую приёмку и универсальную сборку.

## Решение

- Единственная архитектура — arm64. Единая цель задана в `scripts/target.sh`.
- Минимальная система — macOS 26. Заказчик поручил убрать старые версии, не назвав номер. Выбрана 26: образ `macos-26-arm64` уже подтверждён прогонами CI GitHub, поэтому автотесты там продолжают запускаться. Есть ли образ с macOS 27, не проверялось. Чтобы поднять минимум, нужно поменять `scripts/target.sh`, `Package.swift` и образ в CI.
- Убрано: выбор архитектуры в скриптах, подбор Writing Tools по имени свойства, замена `assumeIsolated`, разбиение на `Group` из-за лимита ViewBuilder в Swift 5.8, устаревшая форма `onChange`.
- Сборка оптимизирует модуль целиком (`-wmo`).

## Последствия

- Новые сборки не запускаются на Intel и на macOS ниже 26. Старый Intel-Mac остаётся только источником архива.
- Формат данных не менялся: схема v5, архив `.minervabackup` прежний. Архив со старого Mac восстанавливается здесь. Обратный перенос на Intel больше не цель, сборка для него есть только в истории Git.
- Перед выпуском не нужны проверка на физическом Intel и универсальная сборка.
- `electron/` — порт для Windows, а не сборка для Intel-Mac. Он не входит в личную сборку и этим решением не затронут.
- Поле поиска ⌘K осталось на AppKit: замена на SwiftUI не даёт выигрыша, а меняет проверенный ввод.
- Последняя версия с поддержкой Intel сохранена меткой `intel-last` (`dbae856`). Её отдельный репозиторий `Slipcast-dev/Minerva-Noema` удалён 09.11.2026 по решению заказчика.
