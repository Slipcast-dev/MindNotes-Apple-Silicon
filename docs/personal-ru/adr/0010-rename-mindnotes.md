# ADR-0010. Переименование в MindNotes

Статус: принято, 11.11.2026, по решению заказчика.

Новое имя получили: название в интерфейсе и Dock, идентификатор `local.personal.MindNotes`, каталог `Application Support/MindNotes`, пакет `MindNotes.app` и исполняемый файл, `Sources/MindNotes` и цель в `Package.swift`, скрипты сборки, образа и проверочной копии (`local.personal.MindNotes.test`), строки интерфейса, тип вставки блоков `local.personal.MindNotes.blocks`, SQL-функция `mindnotes_norm` (в схеме не хранится), имя автосохранения окна, расширение новых архивов `.mindnotesbackup`.

Перенос данных — как в ADR-0007. При первом запуске `AppEdition.migrateFromPreviousName` берёт самое новое прежнее имя, от которого остались настройки или каталог (сначала Minerva Noema, затем Grizzly Notes), и `LegacyDataMigration` копирует домен настроек и каталог с резервными копиями. У каждого прежнего имени своя отметка (`migratedFromMinervaNoema`), отметки прежних переносов не копируются. Оригиналы остаются. Перенос берёт только одно имя: иначе настройки Grizzly вернули бы ключи, которые пользователь уже удалил в Minerva Noema.

Намеренно оставлено:

- Чтение архивов `.minervabackup` и `.grizzlybackup`: формат тот же (ADR-0003), они видны в списке копий.
- Папка автоматических копий `Minerva Noema <id>` в выбранной пользователем папке: если она уже есть, копии продолжают идти в неё, чтобы ротация видела прежние копии. Новые пространства получают `MindNotes <id>`.
- `application_id` базы `GRZN`, `LICENSE` и уведомление «На основе Grizzly» — по причинам из ADR-0007.
- Верхняя папка `Проекты/Minerva`: в ней настройки Claude Code и записи прежних сессий. Папка проекта (`Minerva/MindNotes/MindNotes`) и репозиторий (`MindNotes-Apple-Silicon`) переименованы 11.11.2026 по поручению заказчика; выпуск 1.0.0 остаётся с прежним именем файлов.
- Прошлые записи `TEST_REPORT.md`, `ACCEPTANCE.md` (хэши выпуска 1.0.0), `CHANGELOG.md` и ADR-0007 описывают события под прежним именем и не переписываются.

Последствия: разрешения macOS (доступ к папкам, уведомления) запрашиваются заново — система ведёт их по идентификатору. Сохранённые размер и положение окна сбрасываются один раз.
