# ADR-0001. Основание для изменения исходников

Статус: принято, 06.11.2026.

LICENSE (Grizzly Proprietary License) запрещает модификации без письменного согласия автора, Slipcast-dev.

Основание: заказчик поручил разработку на этой машине, где `gh` авторизован под аккаунтом `Slipcast-dev` с правами администратора репозитория. Заказчику было прямо сообщено это допущение (правообладатель), он возражений не высказал и подтвердил начало работ.

Следствия: лицензия и уведомления об авторстве не меняются. Сборка личная, распространение не планируется.
