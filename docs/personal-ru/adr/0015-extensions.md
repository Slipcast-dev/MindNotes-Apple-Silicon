# ADR-0015. Расширения: темы, иконки и будущие плагины

Статус: принято 11.11.2026 по просьбе заказчика заложить модульность.

## Решение

Расширение — папка в `~/Library/Application Support/MindNotes/Extensions/<имя>/` с файлом `manifest.json`:

```json
{ "id": "my.theme", "name": "Моя тема", "version": "1.0", "kind": "theme", "minApp": "1.3.0" }
```

Виды (`kind`):

- `theme` — своя тема: `theme.json` с палитрой для светлого и тёмного режима (те же поля, что у встроенных тем: `paper`, `side`, `ink`, `muted`, `line`, `accent`, `soft`, `card`, `primary`, `logo`, `danger` — цвет `#RRGGBB`). Появляется в выборе темы.
- `appIcon` — иконка приложения: `icon.png` (1024×1024). Выбирается в настройках, ставится в Dock.
- Будущие виды подключаются тем же реестром (`ExtensionRegistry`): шаблоны страниц, наборы значков страниц, пункты меню «/» с готовыми фрагментами. Незнакомый вид показывается в списке как «не поддерживается этой версией» и не ломает загрузку.

**Чужой код не исполняется**: расширения только декларативные (JSON и картинки). Плагин, который запускает код, — это риск для данных пространства; если он понадобится, нужен отдельный ADR (песочница, отдельный процесс, разрешения).

Ошибка в расширении (испорченный JSON, неверный цвет, слишком большой файл) не мешает запуску: расширение помечается в «Настройки» → «Расширения» с причиной. Там же — «Открыть папку расширений» и «Обновить список».
