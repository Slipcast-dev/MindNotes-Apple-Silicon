# Известные ограничения и риски

- **Apple Silicon.** Код для arm64 только компилируется; запусков и тестов на этой архитектуре не было.
- **Производительность.** Машина разработки слабее контрольной (Intel, 8 ГБ против Apple Silicon, 16 ГБ). Цели AT-17 здесь не подтверждаются.
- **Writing Tools.** На macOS 13 их нет, в SDK 13.3 нет их API, поэтому отключение проверить здесь нельзя.
- **Подпись.** Сборка подписана ad-hoc; это не notarization.
- **Два Quick Look-расширения.** При параллельной установке с Grizzly Finder может выбрать любое из них.
- **Редактор M2 временный.** Каждый блок — отдельное поле: нет выделения через блоки, форматирования, вставки блоков. Заменяется на этапе M3.
- **Боковая панель короче макета.** Пункты поиска, избранного, шаблонов и импорта скрыты до реализации. Библиотека файлов (папки, теги, умные папки) открывается отдельной панелью в разделе «Файлы». В настройках нет пункта экспорта до M7.
- **Настройки файлового режима.** Шрифты, подсветка и типы файлов остаются отдельным окном и содержат пункты исходного Grizzly.
- **История.** Снимки создаются и читаются, но интерфейса просмотра и очистки по сроку ещё нет (M7).
- **Старая библиотека.** Библиотека Grizzly не переносится автоматически: личная сборка начинает с пустой (импорт — M7).
- **Отмена при ошибке навигации.** Если запись не удаётся, переход на другую страницу отклоняется с сообщением, пока запись не восстановится; текст доступен через аварийный экспорт.
