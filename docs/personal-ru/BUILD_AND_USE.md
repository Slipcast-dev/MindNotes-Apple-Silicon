# Сборка, запуск и восстановление

[English](../en/BUILD_AND_USE.md) · **Русский**

Для работы нужен Mac на Apple Silicon с macOS 15 или новее. Для сборки — macOS 26 или новее и Command Line Tools (`xcode-select --install`): сборка идёт на SDK 26+ с целью macOS 15 (ADR-0020). Для JS-тестов нужен Node.js. Сборка для Intel не поддерживается (ADR-0009).

## Сборка

```bash
./scripts/build-app.sh
```

Результат: `build/MindNotes.app`, arm64, подпись ad-hoc (это не notarization). Отладочная сборка в другой каталог:

```bash
SWIFT_OPT=-Onone OUT=build/debug ./scripts/build-app.sh
```

Данные приложения (резервные копии, настройки) лежат в `~/Library/Application Support/MindNotes`; само пространство — в выбранной вами папке.

## Проверочный запуск

Копия с идентификатором `local.personal.MindNotes.test` получает свои настройки и свой каталог данных, настоящие данные не затрагиваются. Пространство для неё выбирайте только во временной папке.

```bash
./scripts/run-isolated.sh
```

Завершить копию и удалить всё, что она создала, кроме выбранного пространства:

```bash
./scripts/run-isolated.sh clean
```

## Тесты

```bash
./scripts/test.sh
```

Быстрый набор рабочего пространства без UI:

```bash
./scripts/test-notes.sh
```

Границы слоёв:

```bash
./scripts/check-layers.sh
```

Thread Sanitizer:

```bash
NOTES_OPT=-sanitize=thread ./scripts/test-notes.sh
```

Замеры на данных AT-17. Первый запуск создаёт пространство в указанной папке, она должна быть временной. Замер имеет смысл только с оптимизацией: обычный `test-notes.sh` собирает без неё.

```bash
NOTES_OPT="-O" ./scripts/test-notes.sh --bench-large /tmp/mindnotes-large
```

## Пространство

При первом запуске создайте пространство в пустой папке на локальном диске. Не размещайте активное пространство в папках облачной синхронизации: это не поддерживается. Для переноса используйте архив.

Папка содержит `workspace.sqlite`, каталог `assets/` и служебные файлы. Копировать только `workspace.sqlite` нельзя: часть данных может находиться в журнале WAL.

## Резервная копия и восстановление

«Резервные копии» → «Создать копию» сохраняет архив в `~/Library/Application Support/MindNotes/Backups/`. «Сохранить копию как…» позволяет выбрать другое место. Копия на том же диске не защищает от его отказа, поэтому храните её и на другом носителе.

«Восстановить из архива…» создаёт новое пространство в новой пустой папке и сначала проверяет контрольные суммы и целостность. Текущее пространство не меняется.

Архив `.mindnotesbackup` — обычный tar; его содержимое можно посмотреть командой `tar -tf`.

## Импорт

«Импорт» в боковой панели: источники (Markdown или текст, таблица CSV, папка, экспорт Notion) и недавние файлы — их можно посмотреть без изменений и импортировать как страницы. Сами файлы не меняются.

## Обновления

«Настройки» → «Обновления»: «Автоматически» (проверка выпусков на GitHub при запуске и раз в сутки) или «Вручную» («Проверить сейчас», меню «MindNotes» → «Проверить обновления…»). Найдено обновление — окно «Доступна версия X»: «Скачать и установить» или «Позже». Образ сверяется по SHA-256, приложение устанавливает его и перезапускается (ADR-0014).

## Расширения

Свои темы и иконки приложения — папки с `manifest.json` в папке расширений («Настройки» → «Расширения» → «Открыть папку расширений»). Формат и пример — `EXTENSIONS.md` (ADR-0015).

## ИИ

Необязателен и выключен по умолчанию: «Настройки» → «ИИ» → «Включить ИИ», выбрать провайдера, вставить ключ (локальным Ollama и LM Studio он не нужен) и «Проверить». ⌘J или «✦ Спросить ИИ» над выделением, пробел на пустой строке, ⌘L — чат. Агент сначала предлагает любое изменение. Подробно — `AI_GUIDE.md`.

## Пароль на страницу

«…» у страницы, записи, базы или папки → «Поставить пароль…». Замок закрывает всё внутри. Открыть — паролем, Touch ID или паролем Mac; снова закрывается после сна экрана, перезапуска или «Закрыть на замок». Это замок приложения, а не шифрование (ADR-0017): резервные копии и файл пространства паролем не защищены.

## Редактор

Меню блоков: `/` в начале строки или после пробела. Сокращения: `# `, `## `, `### `, `- `, `1. `, `[] `, `> `, `---`. Форматирование: ⌘B, ⌘I, ⌘U, ⇧⌘X, ⌘E, ⇧⌘K; те же действия в меню «Формат», по правому клику и на панели при выделении. Tab и Shift+Tab меняют вложенность. Убрать форматирование — ⌃⌘\\ (⌘\\ сворачивает боковую панель).

## Сочетания клавиш

«Настройки» → «Сочетания клавиш»: все команды и их стандартные сочетания. Нажмите на сочетание и введите новое с ⌘ или ⌃; Esc — отмена, ⌫ — убрать сочетание. Если сочетание было у другой команды, там оно снимается. ↺ возвращает стандартное для одной команды, «Сбросить все» — для всех. В боковой панели у «Поиска» и «Notes AI» видны их текущие сочетания.

## Импорт и экспорт

«Импорт» в боковой панели принимает файл Markdown, CSV, папку или архив экспорта Notion (`.zip`). CSV открывается с предпросмотром: кодировка, разделитель, строка заголовков, тип каждого столбца. Папка и архив импортируются под новую страницу «Импорт — …» с отчётом в начале; чтобы отменить импорт, отправьте её в корзину. Оригиналы не меняются.

Экспорт: страница — «…» → «Экспорт в Markdown…», база — «Экспорт в CSV…», всё пространство — «Настройки» → «Экспорт». Экспорт не заменяет резервную копию: история, представления и корзина в него не входят.

## Демо-пространство

```bash
./scripts/make-demo.sh
```

Создаёт `build/demo/Демо-пространство` с вымышленными страницами и базой «Задачи», проверенный архив рядом с ним и печатает его SHA-256. Существующее демо не перезаписывается.
