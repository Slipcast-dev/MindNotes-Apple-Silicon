# Расширения MindNotes

[English](../en/EXTENSIONS.md) · **Русский**

Расширения — папки в `~/Library/Application Support/MindNotes/Extensions/` («Настройки» → «Расширения» → «Открыть папку расширений»). Код из расширений не исполняется: только описание и картинки (ADR-0015). После правки нажмите «Обновить список».

## Своя тема

```
Extensions/ocean/
  manifest.json
  theme.json
```

`manifest.json`:

```json
{ "id": "my.ocean", "name": "Океан", "version": "1.0", "kind": "theme", "minApp": "1.3.0" }
```

`theme.json` — все поля для светлого и тёмного режима, цвета `#RRGGBB`:

```json
{
  "light": { "paper": "#FFFFFF", "side": "#F1F6FA", "ink": "#1C2B36", "muted": "#5F7383", "line": "#DDE6EE",
             "accent": "#1F6FB2", "soft": "#E6EFF7", "card": "#FFFFFF", "primary": "#1F6FB2", "logo": "#1F6FB2", "danger": "#C0392B" },
  "dark":  { "paper": "#13202B", "side": "#0F1A23", "ink": "#E3EDF5", "muted": "#9AB0C0", "line": "#26394A",
             "accent": "#6FB3EA", "soft": "#1D3142", "card": "#182836", "primary": "#2B6EA3", "logo": "#2B6EA3", "danger": "#E8988F" }
}
```

Выбор: «Настройки» → «Своя тема».

## Иконка приложения

`manifest.json` с `"kind": "appIcon"` и `icon.png` 1024×1024 (до 5 МБ). Выбор: «Настройки» → «Иконка приложения».

## Дальше

Новые виды (шаблоны страниц, наборы значков, готовые фрагменты для меню «/») подключаются тем же реестром `ExtensionRegistry`. Незнакомый вид показывается как «не поддерживается этой версией» и ничего не ломает.

## Плагины

Плагин — пакет `Имя.mnplugin` с `manifest.json` вида `"kind": "plugin"` (ADR-0019). Его код работает **вне** MindNotes (в браузере, своей программе) и обращается к приложению через локальный API `http://127.0.0.1:27183` только в пределах разрешений из манифеста.

Установка: двойной щелчок по пакету или «Настройки» → «Расширения» → «Установить плагин…». MindNotes покажет разрешения и спросит согласие; там же плагин выключается, удаляется (в корзину) и отключаются подключённые браузеры.

```json
{ "id": "my.plugin", "name": "Мой плагин", "version": "1.0.0", "kind": "plugin", "api": 1,
  "permissions": ["pages.list", "pages.create"], "components": { "chrome": "browser/chrome" } }
```

| Разрешение | Что даёт |
|---|---|
| `pages.list` | названия страниц и папок, куда можно сохранять (без закрытых паролем, баз и записей) |
| `pages.create` | создавать страницы (`POST /v1/clips`) |
| `pages.open` | показывать страницу в MindNotes |
| `assets.create` | добавлять картинки во вложения |
| `tags.write` | ставить теги на созданные страницы |

Обновления плагина ищутся в выпусках с тегами `<updates><версия>` (например, `webclipper-v1.0.1`). Если плагин живёт в своём репозитории, укажите `"repository": "владелец/имя"` — только имя на GitHub, без адреса; без поля выпуски ищутся в репозитории MindNotes.

Клиент подключается так: `POST /v1/pair {"plugin": "<id>"}` — MindNotes спрашивает «Подключить?», после согласия возвращает токен. Дальше каждый запрос — с `Authorization: Bearer <токен>`. Из браузера принимаются только страницы расширений; обычный сайт API не видит.

Первый плагин — **Web Clipper** (`Plugins/WebClipper/`): статьи, выделенный текст, закладки, скриншоты и картинки из Chrome и Safari. Он ставится программой-установщиком `MindNotes Web Clipper.app` (сборка `./scripts/build-webclipper.sh`): она сама добавляет плагин в MindNotes и расширение во все найденные браузеры, а подключение к MindNotes настраивается без вопросов в течение 10 минут после установки (кнопка «Подключить браузеры» в настройках плагина открывает это окно снова).
