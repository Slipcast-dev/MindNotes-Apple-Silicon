# Матрица приёмки 1.0

Сценарии AT-01–AT-18 из ТЗ и доказательства по ним. Состояние на 10.11.2026. Устройство: MacBook Air M1, 8 ГБ, macOS 27.2.

Обозначения:
- **Авто** — автотест в `./scripts/test.sh`, прогон `passed=7124 failed=0`, Node 32 из 32;
- **Вид** — проверочная программа на настоящих видах приложения или запуск изолированной копии;
- **Руками** — проверка заказчика, автоматически надёжно не проверяется.
