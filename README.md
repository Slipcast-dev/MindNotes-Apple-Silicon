# MindNotes

A personal, local knowledge base for Mac: pages, a block editor, search, links and Notion-style databases. Data stays on this Mac; no network or account is needed.

**Download:** [MindNotes 1.1.0](https://github.com/Slipcast-dev/MindNotes-Apple-Silicon/releases/latest) — a `.dmg` for Apple silicon Macs with macOS 26 or later.

> **Apple Silicon only: arm64, macOS 26 or newer.**

## Features

- Pages and subpages, a block editor, trash and version history with restore
- ⌘K search, `[[` links, backlinks, favourites, tags, templates
- Databases: table, board, list, calendar, gallery and timeline views; relations, rollups, formulas, people and file properties; filters, sorts, grouping and manual order
- Images, files and video attachments
- Import of Markdown, CSV, folders and Notion exports; export to Markdown and CSV
- Manual and automatic backups

Project documents are in Russian: see [README.ru.md](README.ru.md) and [docs/personal-ru](docs/personal-ru/STATUS.md).
